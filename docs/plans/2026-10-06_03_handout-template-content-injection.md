## 1. 개요 및 배경

### 1-1. 문제 제기
- 유인물 제작소에서 다운로드 생성 시, B4 세로형(Portrait) 템플릿(`default_b4_question.hwpx`, `default_b4_explanation.hwpx`)의 양식 틀에 실제 문항 데이터가 정상 주입되지 않거나 서식이 유실되는 현상 발생.

### 1-2. 근본 원인 분석
1. **정적 마스터 템플릿과 다운로드 파일의 구분**:
   - `static/data/templates/` 폴더 내의 파일은 변경되지 않는 **원본 마스터 양식(Template)**입니다.
   - 실제 문항 데이터가 추가된 결과물은 사용자가 웹 화면에서 다운로드 버튼을 눌렀을 때 생성되는 **`문제지_유인물.hwpx` / `해설지_유인물.hwpx` (C드라이브 다운로드 폴더 저장)** 파일입니다.
2. **현재 백엔드 생성 엔진의 템플릿 파괴(`sec0_root.clear()`)**:
   - 기존 `hwpx_generator.py`가 상단 1x3 표(`header`)만 추출한 후 `sec0_root.clear()`로 템플릿의 나머지 구조를 모두 삭제함.
   - **해설지 템플릿의 핵심 요소인 1행 4열 출처 표(년도|학년|월|번호)**와 **문제지 템플릿의 지문/선지 전용 단락 스타일(`paraPrIDRef="35"`, 14pt 양쪽정렬)**이 전부 버려지고 기본 텍스트(`paraPrIDRef="0"`)로만 렌더링되고 있었음.

## 3. 세부 구현 계획

### 3-1. 1단계: 해설지 1행 4열 기출 출처 표 보존 및 주입
- `default_b4_explanation.hwpx`의 `P#00` (좌측단) 및 `P#06` (우측단)에 위치한 1x4 `tbl` 엘리먼트 추출.
- DB의 지문 식별자(`[고2-2024년-03월-18번]`)에서 파싱한 연도(`2024`), 학년(`고2`), 월(`3월`), 번호(`18번`)를 각 셀에 주입.
- 셀 내 빨간색 글자 색상을 검은색(`normal_char_id`)으로 자동 정규화.

### 3-2. 2단계: 템플릿 단락 서식 승계형 본문 렌더링
- `_create_paragraph` 호출 시 하드코딩된 `paraPrIDRef="0"` 대신 템플릿의 양쪽 정렬 서식(`paraPrIDRef="35"`)을 사용하여 지문 본문과 선지의 가독성을 실제 모의고사 수준으로 향상.
- 해설지 해설 텍스트 주입 시에도 템플릿의 `paraPrIDRef="27"` 해설 서식 적용.

### 3-3. 3단계: 다페이지(2문항 초과) 유인물 구조화
- 1페이지 = 좌측 1문항 + 단 나눔(`<hp:p columnBreak="1"/>`) + 우측 1문항.
- 홀수 번째 문항 종료 후 단 나눔, 짝수 번째 문항 종료 후 페이지 나눔(`<hp:p pageBreak="1"/>`) 자동 적용.
- 템플릿의 기본 규격(B4 Narrowly, 2단 신문 다단, 0.4mm 중앙 구분선)을 모든 페이지에 완벽히 유지.
