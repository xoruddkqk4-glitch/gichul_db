# 구현 계획서: 복수 단어 따옴표 구문 검색(Exact Phrase) 및 검색창 도움말 UI 구축

**작성일시**: 2026-10-16  
**상태**: ✅ 완료  
**관련 요청**: 복수 단어로 이루어진 표현의 구문 검색(Exact Phrase Match, `""`) 지원 및 일반 검색/따옴표 검색 도움말 UI 추가  

---

## 1. 개요 및 목표

현재 수능·모의고사 영어 기출 DB의 전문 검색(FTS5)은 여러 단어를 입력할 경우 단어 간 `AND` 조건으로만 검색되어, 숙어나 관용구(예: `"in terms of"`, `"take care of"`, `"deal with"`)처럼 **단어들이 순서대로 연속해서 붙어 있는 '정확한 구문(Exact Phrase)'**을 타깃하여 검색하기 어려운 한계가 있습니다. 또한 따옴표(`"`)를 입력해도 백엔드에서 특수문자로 간주되어 제거되었습니다.

본 계획서는 다음 두 가지 핵심 목표를 달성합니다:
1. **정확한 구문 검색 엔진 구축**: 큰따옴표(`"..."`)로 감싸진 검색어는 SQLite FTS5의 **Phrase Query**로 전달하여 인접한 연속 표현만 정확히 검색하고, 화면의 형광펜 하이라이트와 1:1로 일치시킵니다.
2. **검색창 가이드 & 도움말 UI 추가**: 홈 검색 화면과 결과창 검색바에 일반 검색(AND), 따옴표 검색(Phrase), 태그(#), 출처([ ]) 및 단어 단위 검색의 차이를 사용자가 한눈에 알기 쉽게 안내하는 **도움말 툴팁/팝오버**와 **직관적인 플레이스홀더**를 구축합니다.

## 3. 세부 설계 및 구현 내용

### 3.1. [1단계] 백엔드 FTS5 및 LIKE 검색 엔진 구문 파싱 고도화 (`gichul/database.py`)

#### (1) `_build_fts_query` 구문 추출 로직 개선
- **위치**: [gichul/database.py](file:///c:/Users/user/Desktop/web%20app/05-gichul_db/gichul/database.py#L1580-L1591)
- **개선 로직**:
  1. 정규식 `r'"([^"]+)"|(\S+)'`를 사용하여 큰따옴표로 묶인 구문(Phrase)과 일반 단어(Word)를 명확히 분리합니다.
  2. **따옴표로 묶인 구문 (`phrase`)**:
     - 구문 내부의 FTS5 제어문자(`*`, `(`, `)`, `{`, `}`, `^`, `~`, `:`, `+`, `-`)만 공백으로 정제하고, 내부 공백으로 분리된 단어들을 인접 배치합니다.
     - FTS5 Phrase 쿼리 규격인 `"{clean_phrase}"`로 생성하여 인접 토큰의 순서 일치 검색을 보장합니다.
  3. **일반 단어 (`word`)**:
     - `whole_word=True`인 경우: `"{word}"` (온전한 단어 일치)
     - `whole_word=False`인 경우: `"{word}"*` (접두사 일치 가속화)
  4. 추출된 토큰들을 공백(AND)으로 결합하여 FTS5 MATCH 식을 완성합니다.
  - **예시**:
    - `"climate change"` 입력 시 ➔ `'"climate change"'` (정확한 구문 검색)
    - `take "care of"` 입력 시 ➔ `'"take"* "care of"'` (`take` 포함 AND `care of` 구문 연속)

#### (2) FTS 실패 시 폴백(`_use_fts=False`) LIKE 검색 대응
- 따옴표로 감싸진 구문이 포함된 경우, `LIKE ?` 파라미터에 `f"%{clean_phrase}%"` 형태로 전달하여 구문 연속성이 보장되도록 지원합니다.

### 3.2. [2단계] 프론트엔드 검색어 파싱 및 구문 하이라이트 연동 (`static/js/search.js`)

#### (1) `highlightTextKeyword` 정규식 고도화
- **위치**: [static/js/search.js](file:///c:/Users/user/Desktop/web%20app/05-gichul_db/static/js/search.js#L143-L163)
- **개선 내용**:
  1. `rawQuery`에서 큰따옴표(`"..."`) 구문과 일반 단어를 분리합니다.
  2. 따옴표 구문이 있으면 따옴표 안의 문구 전체(공백은 `\s+`로 치환)를 1차 우선 매칭 패턴으로 등록합니다.
  3. 따옴표가 없는 일반 검색어의 경우:
     - 여러 단어가 공백으로 나뉘어 들어온 경우, 전체 문구 연속 매칭뿐만 아니라 개별 단어 단위로도 형광펜 하이라이트가 올바르게 칠해지도록 정규식 대안(`phrase|word1|word2`)을 지원합니다.
  4. 이를 통해 **"검색 결과 목록에는 나왔는데 본문에 형광펜이 전혀 없는"** 기존의 시각적 불일치를 완전히 해결합니다.

### 3.3. [3단계] 검색창 화면 도움말 UI 추가 (`templates/index.html`, `static/css/search.css`)

#### (1) 플레이스홀더(Placeholder) 가이드 강화
- **홈 검색창 (`#mainSearchInput`)**:
  - 기존: `키워드, 문장, 출처([고3-2026년...]) 또는 #태그(예: #빈칸, #어법)를 입력하세요...`
  - 변경: `단어, "연속된 구문·숙어", 출처([고3-2026년...]) 또는 #태그(#빈칸)를 입력하세요...`
- **결과창 검색창 (`#resultsSearchInput`)**:
  - 기존: `검색어, 출처 또는 #태그를 입력하세요...`
  - 변경: `검색어, "정확한 구문" 또는 #태그를 입력하세요...`

#### (2) 검색 도움말 툴팁/팝오버 UI 신설
- **홈 검색 화면 (`#homeSearchView`)**:
  - 검색창(`.google-search-box`) 바로 우측 상단 또는 검색 버튼 옆에 세련된 **`💡 검색 팁`** 가이드 버튼 추가.
  - 마우스 호버 또는 클릭 시 고급스러운 글래스모피즘 팝오버 카드 노출:
    ```html
    <div class="search-help-popover" id="homeSearchHelpPopover">
      <div class="search-help-title">💡 검색 가이드</div>
      <ul class="search-help-list">
        <li><strong>일반 검색</strong> <code>climate change</code> : 두 단어가 모두 포함된 지문·문장 검색 (순서 무관 AND)</li>
        <li><strong>따옴표 구문</strong> <code>"take care of"</code> : 단어가 붙어 있는 정확한 숙어·연어 검색 (Exact Phrase)</li>
        <li><strong>단어 단위 토글</strong> : <code>it</code> 검색 시 <code>situation</code> 제외, 온전한 독립 단어만 검색</li>
        <li><strong>문항 유형</strong> <code>#빈칸</code>, <code>#어법</code> : 해당 유형의 기출 문항만 즉시 필터링</li>
        <li><strong>출처 검색</strong> <code>[고3-2026년-9월-31번]</code> : 특정 시험 문항 바로가기</li>
      </ul>
    </div>
    ```
- **결과창 검색 화면 (`#resultsView`)**:
  - 결과창 검색바의 `단어 단위` 토글 버튼 우측에 컴팩트한 `ℹ️` 버튼 및 미니 팝오버를 배치하여 언제든 검색 팁을 열람 가능하도록 구성.

#### (3) 스타일링 (`static/css/search.css`)
- 기존 다크/모던 톤과 조화를 이루는 팝오버 CSS (부드러운 그림자, 라운드 코너, 폰트 가독성, 반응형 화면 대응).
