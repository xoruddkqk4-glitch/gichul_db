## 1. 개요 및 사용자 요구사항 반영

교사의 입장에서 수능·모의고사 기출 검색 결과 중 원하는 문항들을 선택하여, 수업 및 시험 대비에 즉시 활용할 수 있는 **B4 단면 2문항 규격의 HWPX 문제지 및 해설지 유인물**을 제작하는 기능입니다.

### 🎯 핵심 설계 원칙 및 확정 사항 (선생님 최신 피드백 반영)
1. **지문 유인물 우선 집중**: 문장 유인물은 차후 단계로 분리하고, 우선 **지문 유인물(문제지 + 해설지 B4 HWPX)** 완성에 100% 집중합니다.
2. **철저한 코드 격리와 모듈화**: 기존 핵심 코드(`results-passage.js`, `search.js` 등)를 복잡하게 뒤섞지 않고, **독립 모듈(신규 JS/CSS/Router/Service)**로 완벽히 분리 구현합니다.
3. **사용자 지정 문항 번호(Custom Q Num) 시스템**:
   - 원출처 문항 번호(예: 18번, 21번, 34번)와 별개로, **유인물에 실제로 인쇄될 문항 번호(예: 1, 2, 3... 또는 시작 번호 지정)를 사용자가 직접 자유롭게 입력 및 수정**할 수 있습니다.
   - 문항 목록에서 `[1번부터 자동 재부여]`, `[N번부터 순차 재부여]` 원클릭 보조 도구를 제공합니다.
   - 해설지에는 `1번 [원출처: 2024년 고3 6월 모의평가 21번]` 형태로 매핑되어 문제지와 해설지의 번호가 완벽히 일치합니다.
4. **지문 유인물 구성 요소의 엄격한 정의**:
   - **발문 (Question Title)**: `[사용자 지정 번호]. [발문]` (예: `1. 다음 글의 목적으로 가장 적절한 것은? [2점]`)
   - **지문 (Passage Body)**: 영문 지문 본문 텍스트 (박스 또는 단락 구분)
   - **선지 (Choices)**: ① ~ ⑤번 선지 텍스트
   - **노란색 형광펜 정답 표시**: 정답 번호(예: `③`)에 노란색 형광펜 서식(`markPenBegin` / `shadeColor`) 적용 (교사용 O / 학생 배포용 X 토글 지원)
5. **해설지 텍스트 출처**: 지문 결과 화면의 **왼쪽 하단 패널(`panelExplanation`)에 표출되는 텍스트**(`[정답]`, `[해석]`, `[해설]`, `[어휘]`)가 해설지 HWPX에 그대로 들어갑니다.
6. **출처 정보 노출 규칙**:
   - **문제지**: 학생 평가 및 실전 감각 유지를 위해 **출처 정보 제외** (사용자 지정 번호 + 발문 + 지문 본문 + 선지 ①~⑤)
   - **해설지**: 학생 복습 및 교사 확인을 위해 **출처 정보 포함** (예: `1번 [원출처: 2024년 고3 6월 모의평가 21번 / 정답률 48%]`)
7. **HWPX 양식 사전 업로드 & 재사용**: 선생님 고유의 학교/학원 양식 B4 `.hwpx` 파일을 웹 화면에서 직접 업로드하여 보관하고 언제든 선택해 사용할 수 있습니다. (기본 내장 B4 양식도 함께 제공)
8. **머리말 & 꼬리말 입력/수정 지원**:
   - 유인물 제작 화면에서 문제지와 해설지 각각의 **머리말(학교명, 시험명, 과목)과 꼬리말(페이지 번호, 영어과 문구)**을 직접 입력·수정할 수 있습니다.
   - 최근 입력된 머리말/꼬리말은 브라우저(`localStorage`)에 자동 기억되어 매번 다시 치지 않아도 됩니다.

## 2. 코드 격리 및 모듈 아키텍처 (Clean Separation)

기존 코드가 오염되거나 사이드 이펙트가 발생하지 않도록 신규 기능은 모두 전용 파일에 격리합니다.

```
05-gichul_db/
├── static/
│   ├── css/
│   │   └── handouts.css             # [신규] 유인물 제작 화면 및 장바구니 전용 독립 스타일
│   └── js/
│       ├── handout-cart.js          # [신규] 문항 선택(장바구니) 상태 관리 및 플로팅 배지
│       └── handout-passage.js       # [신규] 지문 유인물 뷰 로직 (문항 정렬, 문항 번호 수정, 머리말/꼬리말 입력, HWPX 생성)
├── gichul/
│   ├── routers/
│   │   └── handouts.py              # [신규] 유인물 전용 REST API 라우터 (/api/handouts/...)
│   └── services/
│       └── hwpx_generator.py        # [신규] HWPX ZIP/XML 템플릿 파싱, 문항 번호 치환, 머리말/꼬리말 주입, 형광펜 엔진
└── templates/
    └── index.html                   # [기존] 유인물 전용 뷰 컨테이너 <section id="handoutViewContainer"> 만 추가
```

* **기존 코드와의 유일한 최소 접점**:
  1. `passage-render.js`: 문항 카드 좌측 상단에 체크박스 `<input type="checkbox" class="handout-q-select">` 렌더링 한 줄
  2. `navigation.js`: `switchView("handout")` 뷰 전환 분기 1개
  3. `gichul/app.py`: `app.include_router(handouts.router)` 라우터 등록 1줄

### 3-1. 지문 결과 화면에서의 문항 선택
- 지문 결과 화면의 각 문항 탭/카드에 `[ ] 유인물 담기` 체크박스 제공
- 문항을 1개 이상 선택하면 화면 우측 하단에 세련된 플로팅 바 노출:
  - `📌 선택된 문항: 4개 (2페이지 분량) ➜ [📄 지문 유인물 제작하기]`

### 3-2. 유인물 제작소 화면 (`#handoutViewContainer`)
- **좌측 영역: 선택된 문항 목록 및 문항 번호 커스텀 관리**
  - **문항 번호 직접 입력 인풋**: 각 카드마다 `[ 1 ] 번` 형태로 교사가 인쇄될 번호를 직접 타이핑 수정 가능
  - **번호 빠른 관리 도구**:
    - `[ 🔢 1번부터 자동 재부여 ]` 버튼
    - `[ 시작 번호: ( 5 )번부터 순차 부여 ]` 버튼
  - **순서 조정 및 삭제**: 위/아래 이동 버튼 (`▲`, `▼`), 개별 삭제(`🗑️`), 목록 전체 비우기
  - 예상 페이지 수 안내 (예: 4문항 선택 시 `총 2페이지 (B4 단면 2문항 기준)`)
- **우측 상단: 머리말 / 꼬리말 설정 영역**
  - **머리말 (Header)**:
    - 문제지 머리말: 예) `2026학년도 1학기 기말고사 대비 영어 기출 모의고사`
    - 해설지 머리말: 예) `2026학년도 1학기 기말고사 대비 영어 기출 정답 및 해설`
    - 소제목/부서: 예) `고등학교 2학년 / 영어과`
  - **꼬리말 (Footer)**:
    - 좌측 꼬리말: 예) `OO고등학교 영어과`
    - 우측 꼬리말: 예) `- 1 -` (페이지 번호 플레이스홀더 지원)
- **우측 중단: 템플릿 관리 영역**
  - B4 템플릿 선택 드롭다운 (기본 B4 시험지 양식 / 사용자 등록 양식)
  - `[+ 새 HWPX 양식 업로드]` 버튼 (클릭 시 B4 HWPX 파일 등록 및 영구 저장)
- **우측 하단: 다운로드 액션**
  - `[ 정답 형광펜 표시 ]` 토글 스위치 (교사용 O / 학생용 X)
  - `[📄 문제지 다운로드 (HWPX)]`
  - `[📘 해설지 다운로드 (HWPX)]`
  - `[📦 문제+해설 일괄 다운로드 (ZIP)]`

## 4. 백엔드 HWPX 생성 엔진 설계 (`hwpx_generator.py`)

### 4-1. 초고속 ZIP/XML 조작 메커니즘
- HWPX 파일은 ZIP 컨테이너 구조:
  - `Contents/section0.xml` : 본문 및 2단 단락 구조
  - `Contents/header.xml` : 글자 모양(`<hh:charPr>`), 문단 모양(`<hh:paraPr>`)
- Python 표준 라이브러리 `zipfile`과 `xml.etree.ElementTree`를 사용하여 0.05초 만에 메모리 내에서 생성하여 바로 스트리밍 응답(`StreamingResponse`).

### 4-2. 문제지 vs 해설지 텍스트 주입 규칙
1. **문제지 (Question Paper)**:
   - **출처 정보**: **완전 배제** (학생 평가용)
   - **문항 번호**: 사용자가 지정한 `custom_q_num` (예: `1`, `5`, `1-1` 등)
   - **발문 (Question Title)**: 기존 발문 앞의 원래 번호(예: `18.`, `21.`)를 제거하고 사용자가 지정한 번호로 치환 (예: `1. 다음 글의 목적으로 가장 적절한 것은? [2점]`)
   - **지문 (Passage Body)**: `clean_question_explanation_leak(p.passage_text)` 순수 영문 지문
   - **선지 (Choices)**: `extract_choices(p.passage_text)`를 통해 ① ~ ⑤번 분리
   - **형광펜 처리**: 교사용 모드일 때 정답 번호(예: `③`)에 `<hp:markPenBegin color="#FFFF00"/>` 또는 `<hh:charPr shadeColor="#FFFF00">` 적용. (학생용 모드일 때는 일반 번호로 출력)

2. **해설지 (Explanation Paper)**:
   - **문항 헤더**: 사용자 지정 문항 번호와 원출처 병기 (예: `1번 [원출처: 고3 2024년 6월 모의평가 21번 / 정답률 48%]`)
   - **해설 본문**: 지문 결과 화면의 왼쪽 하단 패널(`panelExplanation`)에 들어가는 원본 텍스트 (`combineGroupExplanations` 포함)
   - `[정답]`, `[해석]`, `[해설]`, `[어휘]` 섹션을 가독성 높은 소제목 단락으로 자동 스타일링하여 주입

3. **머리말 & 꼬리말 주입**:
   - `section0.xml` 내의 머리말(`<hp:header>`) 및 꼬리말(`<hp:footer>`) 노드의 `<hp:t>` 텍스트를 사용자가 웹 화면에서 입력한 텍스트로 치환

## 5. 단계별 구현 로드맵 (총 4단계)

```
[1단계: 백엔드 HWPX 템플릿 엔진 & 기본 B4 양식 제작]
 ├── 기본 B4 단면 2문항 템플릿(문제지/해설지) 생성 및 data/templates/ 에 저장
 ├── gichul/services/hwpx_generator.py 구현:
 │    ├── 사용자 지정 문항 번호(custom_q_num) 치환 로직
 │    ├── 머리말/꼬리말 동적 치환
 │    ├── 문제지 생성 (출처 제외, 발문+지문+선지 분리, 정답 번호 노란색 형광펜 하이라이트)
 │    └── 해설지 생성 (사용자 번호+원출처 병기, 좌측하단패널 해설 텍스트 주입)
 └── 단위 테스트(tests/test_hwpx_generator.py)로 생성 파일 무결성 검증

[2단계: 유인물 전용 REST API 라우터 구현]
 ├── gichul/routers/handouts.py 생성
 │    ├── POST /api/handouts/generate-passage (문항 목록, custom_q_num, 머리말/꼬리말 파라미터 수신 및 파일 스트리밍)
 │    ├── GET  /api/handouts/templates (등록된 템플릿 목록)
 │    └── POST /api/handouts/templates/upload (선생님 자체 HWPX 양식 업로드 및 저장)
 └── gichul/app.py에 라우터 등록

[3단계: 프론트엔드 장바구니 및 모듈 격리 구현]
 ├── static/css/handouts.css 작성 (독립 스타일)
 ├── static/js/handout-cart.js 작성:
 │    ├── 문항 선택/해제 상태 관리 (localStorage 동기화)
 │    └── 화면 우측 하단 플로팅 바 UI
 └── passage-render.js에 최소한의 체크박스 렌더링 코드 연동

[4단계: 지문 유인물 제작소 화면 및 다운로드 완성]
 ├── templates/index.html 내 <section id="handoutViewContainer"> 추가
 ├── static/js/handout-passage.js 작성:
 │    ├── 선택 문항 목록 및 사용자 지정 문항 번호 인풋/자동 재부여 도구
 │    ├── 순서 변경(위/아래) 및 개별 삭제
 │    ├── 머리말/꼬리말 입력 폼 바인딩 (localStorage 자동 저장)
 │    ├── HWPX 템플릿 업로드 및 선택 기능
 │    └── 문제지/해설지/ZIP 다운로드 비동기 호출
 └── 터미널 정적 검증 (Python/JS 구문 검사)
```
