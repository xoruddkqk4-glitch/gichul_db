# docs — 계획서 · 리뷰 문서 보관소

이 폴더는 에이전트(`/ask`, `/apply`)와 사용자가 함께 쓰는 **계획서와 분석 문서**를 모아 두는 곳입니다.
소스 코드는 두지 않습니다.

## 폴더 구조와 이름 규칙

```
docs/
├── README.md          # 이 파일: 전체 목록과 상태 (새 문서를 추가할 때마다 갱신)
├── plans/             # 구현 계획서 (/ask 가 작성, /apply 가 실행)
│   └── YYYY-MM-DD_<영문-주제-슬러그>.md
└── reviews/           # 코드 리뷰, 분석 보고서 (코드 변경 없음)
    └── YYYY-MM-DD_<영문-주제-슬러그>.md
```

- 같은 날 문서가 여러 개면 `YYYY-MM-DD_01_...`, `YYYY-MM-DD_02_...`처럼 순번을 붙입니다.
- 계획서는 **덮어쓰지 않고** 새 파일로 추가합니다. 진행 상황은 각 계획서 안의 "진행 현황" 표와 아래 목록에 함께 기록합니다.
- 상태 표기: ⬜ 대기 · 🔄 진행 중 · ✅ 완료 · ⏸ 보류 · ❌ 폐기
